# 模式标记优化（2026-10-08）

用户反馈工作区顶部的「实时增强／本地媒体」方框不够自然。
当前模式改在底部状态栏左侧常驻显示，采用无描边的小圆角标记，融入已有状态信息。

## 行为

- 工作区不再创建任何模式提示浮层。模式标记固定在状态栏布局中，保持可读，鼠标和键盘不把它当作按钮。
- 两种模式共用按当前语言最长名称测量的宽度，切换时不挤动宿主状态／进度信息。
- 成功切换后文字短暂提亮，再在 700 ms 内恢复到正常次要文字颜色；形状、大小、位置保持不动。
  系统动画关闭时采用静态提亮，700 ms 后一次恢复颜色。
- 更新主题和模式复用同一个标记；创建失败保留上一模式名称，连续切换取消旧定时回调。
  手动换肤取消提亮，继续显示当前模式；隐藏工作台照常更新名称，不运行提亮动画。
- 沿用上一轮统一换色修复。主题反转、模式切换、媒体／队列／实时会话规则保持原有行为。
