# 实时界面反馈修复（2026-10-04 至 2026-10-05）

## 根因与改动

### 滚轮回调

截图的 `AttributeError: 'str' object has no attribute 'winfo_class'` 来自 `RealtimeWorkspace.on_mousewheel`。Tk 自己创建的下拉弹出列表没有对应 Python 控件对象，事件中的 `widget` 可能是 Tcl 路径字符串。旧逻辑直接调用控件方法，导致滚轮不断触发异常；与 DLSS 渲染初始化无关。

新逻辑解析可识别的路径；未知弹出列表、销毁中的控件及空滚动区域安全返回，不吞掉列表自身的滚轮事件。已用实际 Tcl combobox popdown 路径和已销毁控件回归，同时确认普通检查器仍可滚动。

### 可选多遍增强

已安装 NR 效果元数据的 `multiPass` 原本默认是 1，旧 UI 的第 2／3 遍标题表示参数分组，不代表这两遍默认运行。为了消除歧义：

- 两个分组标题右侧新增明确勾选开关，并区分「已选用／未选用」；展开参数不改变启用状态。
- 默认配置和缺少 `multiPass` 的旧配置显式采用 1；用户预设明确设置的 2／3 不覆盖。
- 第 3 遍要求先启用第 2 遍，关闭第 2 遍同时关闭第 3 遍；各遍参数保留。
- 共用原有撤销、实时确认和显式重启流程；标题表示编辑选择，不冒充已在运行中生效。
- 元数据完整时使用开关替代高级分组中重复的遍数选择器；恢复高级组不隐式关闭另组的多遍开关。元数据不完整时保留原始遍数控件，不丢失入口。
- 布局测试捕获并修复了标题 Canvas 先占满窄栏、开关被挤掉的问题，改为先预留开关宽度。

### 可读日志

`realtime_logs.py` 将原生协议消息与用户日志分离：底栏采用本地风格的 `[实时] ...`／`[Realtime] ...` 文本，显示引擎连接、设备发现、实际状态、已确认参数保存和错误提示；不把 ACK 当作渲染成功，也不输出整块设备 JSON、成功 ACK 和高频遥测。

常见原生失败双语映射为原因和操作建议，保留错误编号；未知第三方／引擎消息保留原文，不编造翻译或静默丢弃。连续重复状态去重，界面日志限长，保留浏览旧日志时的滚动位置。原始事件仍进入已有诊断 journal，遵守其原有保留上限；日志界面简化不改变诊断导出内容。
