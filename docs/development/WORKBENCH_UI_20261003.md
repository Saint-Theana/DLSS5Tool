# 单窗口双模式工作台：设计实现与验证

日期：2026-10-03。范围：现有主界面集成；不是发布包，不替代原生渲染、游戏或 HDR 验收。

此文记录第一版工作台。后续已移除独立顶部模式栏，改为原生标题栏图标入口，
会话状态与停止按钮移入底部状态栏，并修复播放器过早换行；当前设计及验证见
[标题栏与播放器布局更新](CAPTION_TOOLBAR_20261003.md)。下文的顶部布局和测试数保留为历史记录。

## 已实现

| 部位 | 本地媒体 | 实时增强 |
| --- | --- | --- |
| 顶部 | 共用模式切换、实时会话状态和停止按钮 | 共用，无新控制 Toplevel |
| 中间 | 原有预览、时间线、画面对比 | 目标窗口、保护区域示意编辑、原生对比/参数/统计/截图操作、运行实测 |
| 右侧 | 原有调整、引导、导出、队列 | 效果、保护、显示、预设、记录；可滚动，保留全部旧控制项 |
| 会话 | 原有素材、帧位置、队列、参数、组件实例保留 | 首次访问时构建，切换保留目标、草稿、滚动位置和运行状态 |

- 主应用直接嵌入 `RealtimeWorkspace`；独立 `RealtimeWindow` 仅留给已有诊断探针，不再被主界面入口调用。
- 切走本地会暂停本地播放，切回不自动播放；不取消导出。手动分离的本地预览在实时模式暂时隐藏，切回恢复同一窗口。
- 切换模式不发送实时 start/stop，不销毁宿主或其状态轮询；首次选择实时只请求效果目录和设备清单，不开始捕获。
- 顶部状态按会话生命周期计算，独立于“已保存预设”等编辑器提示。状态栏使用启动目标快照，不被下拉框的新选择覆盖。
- 源窗口等待恢复仍属于可停止会话；停止中/恢复中保留停止控制。恢复期间停止只取消重启，不重复抢占宿主关闭。
- 实际首帧提交才确认输出；参数与合成设置仍等待后端确认，原有失败回滚路径保留。
- 刷新不自动选择第一个窗口；原 HWND/PID 消失时清空选择，避免无意捕获另一个程序。
- 保护区域坐标跟随编辑画布尺寸归一化，调整窗口大小不会改变已有区域；浅色/深色主题随主界面同步。
- 本地快捷键和文件拖入在实时模式不再误操作隐藏的本地播放器。

## 明确保留的边界

- 中间画布是**保护区域示意图，不是源窗口实时预览**。真实 GPU 画面、画面对比和画面内调参仍由原生输出承载；这不是额外的控制窗口。
- 不把本次 UI 集成说成两条渲染管线合并。本地视频仍使用原有本地导出实现；新增残差/区域保护 GPU 合成仍属于实时路径。
- 实时预设和本地任务参数独立，没有悄悄同步；跨管线共用 NR 预设/本地残差合成仍需专门实现和画质验收。
- 在线视频指捕获正在播放的浏览器或播放器窗口；没有新增 URL 解码、音频捕获或网络播放器。
- 真实游戏、HDR、混合 DPI、多物理 GPU、OBS 并发验收保持原来的未验收状态。
