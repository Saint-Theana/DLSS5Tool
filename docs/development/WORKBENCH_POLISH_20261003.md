# 工作台切换与实时界面 i18n 打磨

日期：2026-10-03，2026-10-04 续改主题规则与减少动画反馈。范围：源码 UI，不打包、不修改渲染算法，不捕获游戏或用户窗口。

2026-10-08 更新：下文的整页滑动揭示已由统一换色与静止提示替代；主题反转规则不变。
当前行为和验证见 [主题切换打磨](THEME_SWITCH_20261008.md)。以下保留历史实现记录。

## 行为

- 标题栏单击、Ctrl+Tab 和文字模式入口均走统一切换：每次实际切换反转当前深／浅主题，不固定模式颜色。切换开始即应用目标主题，包括原生标题栏、按钮、底部状态和两个工作台；「更多」手动换色仍可用，下次切换从当前主题反转。重复选择当前模式不换色、不重播反馈。手动换色会清除旧主题的过渡／提示。
- 内容区进行约 180 ms 的缓出滑动揭示，不截图、不透明化整个应用、不新增窗口。过渡遮罩只在主工作区内，底部停止增强按钮始终可达。
- 连续切换取消旧动画；关闭应用清理定时回调，工作区创建失败撤销动画并恢复之前主题。本地播放暂停、队列和两侧草稿保留、切换不自动启停捕获的规则不变。
- 只读取、不修改 Windows 动画设置；按用户要求，关闭系统动画仍保留应用内轻量反馈：不滑动整页、不移动控件，成功切换后顶部居中显示 900 ms 的模式提示，文字与边框颜色缓入／缓出（首尾各约 160 ms，中段停留），不依赖系统窗口动画或透明度。鼠标移入即收起、不抢焦点；提示沿用当前语言和新主题。隐藏窗口不创建反馈。颜色渐变与滑动过渡共用取消机制，不堆积回调。

## 本地化边界

- 使用现有 `locales/zh_CN.json`、`locales/en_US.json` 和 `i18n.tr`。实时五个标签页、操作、表单、状态、提示、错误与标题栏入口均接入。
- 效果元数据通过 `realtime_labels.py` 映射显示文字；随包参数标签、分组和选项在两种语言中均有条目。原始 `OF Quality` 按参数 ID 区分为 AMD / NVIDIA 光流质量。
- 不修改 shader 源文件、效果名称、参数 ID、枚举数值或预设内容；不修改原始诊断事件。第三方未知元数据回退为可读原文，不显示内部翻译键。
- 沿用应用既有语言流程：语言选择保存后重启生效，不在活动会话中重建整个界面。
