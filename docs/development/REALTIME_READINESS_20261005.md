# 实时摘要、启动检查与说明精简（2026-10-05）

## 实现范围

- `realtime_readiness.py` 提供纯效果链摘要和被动启动检查；`realtime.py` 增加窗口句柄／进程身份及最小化状态读取，不激活窗口。
- 效果链分别显示编辑草稿与已确认运行内容；新会话必须收到输出确认才标记实际运行。重启请求失败保留上次已确认链；等待源窗口时明确标为上次确认，停止后不冒充运行。
- `realtime_ui.py` 将检查结果嵌入现有工作台，区分阻碍与提醒。允许提醒后继续，但每次启动均重查；阻碍不清空现有会话及排队编辑。引擎代次变化后不复用旧快捷键、效果目录和运行库快照。
- 定位操作复用目标选择、「调整／保护／显示／预设」页面、统一诊断导出；NR 文件问题通过 `gui.py` 切到现有本地模块编辑器，不增加顶层窗口。
- `InlineHelp` 将长说明收进原位「详情」，保留悬停及键盘入口；中英文文案同步。参数、多遍开关、算法选择和原始诊断均不裁剪。

## 检查边界

只读检查目标身份、宿主文件、实际宿主启动所选 NR 路径、已知效果目录、重复插帧、HDR 捕获方式和全屏停止快捷键。缺少当前握手或目录时只提醒；NR 精确文件缺失是阻碍，SR／FG 目录未找到文件仅提醒，因为 NGX 仍可能从其他位置解析。

不加载 DLL、不自动下载、不检测驱动／GPU 兼容性、不捕获画面，也不修改用户设置。原生启动校验继续作为最终边界；文件存在不能证明兼容，检查通过不能表述为实际渲染验收。全屏停止键仅在宿主启动时注册，因此提示释放占用后重启应用或切到窗口输出。
