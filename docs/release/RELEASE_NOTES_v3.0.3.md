# v3.0.3 Release Notes

## 修复

- 修复切换不同尺寸图片和反复预览时部分合成资源未及时释放的问题，减少连续使用时的内存累积。
- 完善取消、清理缓存、退出和初始化失败时的资源回收，改善任务异常后的恢复。
- 加强处理和暂停等待时的内存保护，余量不足时及时停止并提示，减少继续处理造成的内存压力。
- 隔离显卡信息查询，减少选卡和预览时对图像处理会话的额外影响。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合先体验基础效果。
- **完整版（full）**：包含主程序、光流推理组件和模型；启用光流可改善连续画面的光影稳定性，也会增加处理耗时。下载全部分卷后合并解压。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。
