- 将 NVIDIA DLSS SDK `lib/Windows_x86_64/rel/nvngx_dlss.dll` 放入冻结包 `_internal/`。
  58,977,904 bytes，SHA256 `be6e434a94ca32499515eb62ca0e6c274526055d568d0426e4c652dcdfb6ee6e`，

## 重建入口

复用 `.venv` 和 `tmp/guidance-cuda-env`，后者 Torch 2.8.0+cu128 / torchvision 0.23.0+cu128 /
NumPy 2.5.2 / OpenCV 5.0.0.93 / PyInstaller 6.22.2。唯一组件候选由当前 `scripts/build_enhancement.py` 生成，
架构来源 `tmp/dlss5standaloneV2/models`，未附深度权重，RAFT 权重保持原 SHA。

```powershell
.venv/Scripts/python.exe -B scripts/release_updates.py --preflight-version v3.0.0
./scripts/build_release.ps1 -SkipInstall -SkipTests -LocalCandidate -OutputDirectory tmp/<task>/base -WorkDirectory tmp/<task>/build
tmp/guidance-cuda-env/Scripts/python.exe -B scripts/build_enhancement.py --depth-source tmp/dlss5standaloneV2/models --depth-license tmp/package-licenses-v2.1.1/DepthAnythingV2-CODE-LICENSE.txt --output tmp/<task>/component
# 验证新的组件；冻结 EXE 的构建时间会影响摘要，确认后更新 WORKER_SHA，不绕过摘要检查。
.venv/Scripts/python.exe -B scripts/package_editions.py --base tmp/<task>/base/DLSS5Tool-v3.0.0 --component tmp/<task>/component/mods/enhancement --models mods/models --licenses tmp/package-licenses-v2.1.1 --output dist/<new-release>/editions --local-candidate
.venv/Scripts/python.exe -B scripts/release_updates.py --check-upload dist/<new-release>/editions/github-assets
```

基础构建的 `-SkipTests` 对应单独运行的 114 项测试，不代表省略验证。重建前再次遵守仓库卫生、空间与基线检查要求。
