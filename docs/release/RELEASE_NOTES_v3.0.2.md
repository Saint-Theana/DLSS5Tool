# v3.0.2 Release Notes

## 优化

- 关闭增强效果或将强度调为 0 时，自动跳过不需要的增强计算，减少额外资源占用；超分、补帧和 HDR 仍按原设置运行。
- 统一本地 SDR 和 HDR 画面的 GPU 合成，减少重复转换和导出时的画面搬运，大尺寸图片和视频的画面合成更快。
- 连续调节预览参数时复用已有合成资源，减少反复创建和等待，预览能更快跟上设置变化。

## 修复

- 修复反复预览后部分资源未及时释放的问题，减少连续使用时的内存占用，并加强内存不足时的保护。
- 修复本地画面合成未跟随增强所选显卡的问题，避免多显卡环境下默认选卡不一致。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合优先考虑处理速度、先体验基础效果的用户。
- **完整版（full）**：包含主程序、光流推理组件和模型；启用光流可改善连续画面的光影稳定性，但会增加处理耗时。下载全部分卷后合并解压。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型，补齐后与完整版一致；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。

首次使用请核对显卡型号；需要更换运行库时，从 [显卡运行库下载页](https://github.com/banbanzhige/DLSS5Tool/releases/tag/zip) 获取对应文件，关闭程序后将 `nvngx_dlssnr.dll` 放入与主程序同级的 `mods` 文件夹。
