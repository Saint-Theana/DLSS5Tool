# v3.0.0 Release Notes

## 新增

- 新增本机实时增强，直接选择正在运行的窗口，以窗口或全屏方式输出增强画面，无需采集卡。
- 新增画面方案与个人预设，可组合细节增强、缩放和插帧，并为需要保留原貌的区域设置保护。
- 本地预览新增「自动预渲染」开关，可按需处理当前画面，也可提前缓存后续帧，并记住上次选择。
- 两种模式统一诊断导出，默认生成轻量报告，需要进一步排查时再选择深度检测。
- 新增本地更新包导入，可选择已下载的官方更新包，联网校验后确认安装。

## 优化

- 本地媒体与实时增强共用一个工作台，按来源、方案、输出和调节分区，并记住上次使用的模式和深浅主题。
- 两种模式统一常用参数，支持分组复制、恢复和撤销；调节更流畅，并显示待处理、更新中和已生效状态。
- 优化两种模式的面板分界拖动与本地画面对比，减少卡顿和残影，支持右键平移查看细节。
- 两种模式协调显卡资源占用，开始、停止和释放时显示进度，避免任务冲突。
- 精简轻量版安装体积，本地硬件光流可直接使用，无需推理附加包。

## 修复

- 修复透明 PNG 增强后透明信息丢失、半透明边缘显示异常的问题。
- 修复部分变帧率视频仅启用超分时无法导出的问题，保留原画面时间戳和兼容音轨。
- 修复预览等待时画面被压暗、进度信息不清晰的问题，保留正常画面并在底部显示处理阶段与等待时间。

## 下载选择

- **轻量版**：包含主程序、本地与实时增强及本地硬件光流，不含 RAFT 推理组件和模型。
- **完整版（full）**：包含轻量版、RAFT 推理组件和模型；下载全部分卷后合并解压。
- **推理附加包（addon）**：为轻量版补装 RAFT 组件和模型；下载全部分卷后合并解压到主程序目录，完整版无需重复安装。
